# GPT Video Bot

Телеграм-бот, который создаёт короткие абстрактные видео (до 60 секунд) без использования платных API. Видеоролики генерируются на лету с помощью бесплатных библиотек NumPy и MoviePy.

## Возможности

- Команда `/start` предлагает выбрать длительность видео: 15, 30, 45 или 60 секунд.
- После выбора бот генерирует и отправляет MP4-файл с абстрактной анимацией.
- Генерация полностью автономна и не требует внешних платных сервисов.

## Запуск

1. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Создайте и активируйте Telegram-бота через [@BotFather](https://t.me/BotFather), получите токен и сохраните его в переменную окружения:

   ```bash
   export TELEGRAM_BOT_TOKEN=123456:ABCDEF...
   ```

3. Запустите бота:

   ```bash
   python -m src.bot
   ```

Бот начнёт работать в режиме long-polling и будет готов принимать команды.

## Примечания

- Генерация видео выполняется локально и может занять до минуты в зависимости от выбранной длительности и возможностей сервера.
- По умолчанию видео создаётся в квадратном формате 640×640 с частотой 24 кадра/сек.
